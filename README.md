# OpenVPS Agent distribution

This repository is the public distribution endpoint for the OpenVPS Linux Agent.

The Agent source code is maintained in the private OpenVPS application repository. This public repository contains only the installer documentation and release binaries.

## One-command installation

Create a server enrollment in the OpenVPS dashboard, copy the generated command, and run it on the target Linux machine.

The installer automatically detects the CPU architecture, downloads the matching release asset, verifies SHA-256, enrolls the machine, installs the systemd service, and starts the Agent.

Supported Linux architectures:

- `amd64`
- `arm64`
- `armv7`

Current installer URL:

```text
https://raw.githubusercontent.com/OpenVPS/Ai-Agent/main/install-agent.sh
```

Latest release assets use these names:

```text
openvps-agent-linux-amd64
openvps-agent-linux-arm64
openvps-agent-linux-armv7
SHA256SUMS
```

The installer requires a Linux host with systemd. On common distributions it can install missing `curl` and `python3` packages automatically through the detected package manager.

Enrollment credentials are generated by the OpenVPS backend and are never committed to this repository.
